# 👑 ZENVORA GAMING

Bot oficial de WhatsApp para administrar el clan ZENVORA GAMING.

## Comandos

- `.menu` — Mostrar comandos.
- `.placas` — Consultar placas personales.
- `.top` — Mostrar TOP 10.
- `.addplacas` — Añadir placas.
- `.delplacas` — Quitar placas.

## Administración

Los comandos para añadir y quitar placas solo pueden ser utilizados por administradores del grupo.

## Inicio

Ejecutar:

npm install
npm start
